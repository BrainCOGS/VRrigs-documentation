## Introduction

This website is the central repository for documentation on the **maintenance** of the mini virtual reality rigs as part of BRAIN CoGS at Princeton Neuroscience Institute.

The maintenance documentation is also divided into modules. Each module covers the procedures and tools for preventive and corrective maintenance, as well as common troubleshooting.
